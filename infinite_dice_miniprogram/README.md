# 无限骰子小程序（微信版）

本目录提供微信小程序版本的完整代码，包含首页 UI 与可交互的掷骰/计分逻辑。

## 快速运行

1. 安装并打开 **微信开发者工具**。
2. 选择「导入项目」。
3. 项目目录选择 `infinite_dice_miniprogram`。
4. AppID 可先使用测试号或「不使用 AppID」。
5. 打开后即可预览并运行。

## 结构说明

- `app.json`：全局配置与页面入口。
- `app.js` / `app.wxss`：全局逻辑与样式。
- `pages/index`：首页 UI 与交互逻辑。

## 页面功能

- **Roll N**：先投 1 个骰子，确定骰子数量。
- **Score**：按当前骰子数量计算得分；N < 3 时触发连击裂变机制。
- **Reset**：清空当前回合与总分记录。
